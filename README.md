# Shelby Financials Dashboard V2 - Handover

- **Live demo:** https://oisin-curran-mb.github.io/Dashboard_V2_Handover/
- **V1 to V2 handover doc:** https://oisin-curran-mb.github.io/Dashboard_V2_Handover/handover.html

The demo covers every widget carried over from V1 plus Financial KPI and Pending Actions; the handover doc covers all of them except Pending Actions, whose section is still to be written. Alerts & Actions is not part of this release. The developer-only data-state dropdown is shown locked to Default. The Permissions and Dashboards tabs (top-right toggle) carry the widget permissions review and the module-by-module default dashboards; the full documents are in docs/handover.
All sample data is mock data.
